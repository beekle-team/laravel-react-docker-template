# Code Simplifier

指定されたファイルまたは直近で編集したファイルのコードを整理・簡素化してください。

## 対象

$ARGUMENTS が指定されていれば、そのファイル/ディレクトリを対象にする。
指定がなければ、このセッションで編集したファイルを対象にする。

## 整理のポイント

### 削除対象
- 未使用のimport / use文
- 未使用の変数・関数
- 冗長なコメント
- デッドコード
- 不要な型アノテーション（自明な場合）

### 簡素化
- 長すぎる関数は分割
- ネストが深いロジックはearly returnで平坦化
- 重複コードは共通化（ただし過度な抽象化は避ける）
- 変数名・関数名を明確に

### やらないこと
- 機能の追加・変更
- 過度な抽象化
- 不要なデザインパターンの導入

## 言語別の注意点

### PHP (Laravel)
- `use` 文の整理（Pint で自動フォーマット可能）
- Eloquent クエリの最適化
- コレクションメソッドの活用
- 型宣言の追加（PHPStan 対応）

### TypeScript (React)
- 未使用の import 削除
- `any` 型の排除
- カスタムフック への抽出
- コンポーネントの適切な分割

## 手順

1. 対象ファイルを読み込む
2. 上記の観点で問題を特定
3. 最小限の変更で整理
4. 変更後に lint を実行して確認
   - PHP: `composer lint`
   - TypeScript: `npm run lint && npm run types`
